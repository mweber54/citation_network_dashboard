1) Project Purpose
This repository contains a computer-science literature pipeline that:
- extracts topic/keyphrase structure from paper metadata,
- builds a keyword-paper hypergraph,
- trains/evaluates a temporal hypergraph neural network (THGNN) for residual forecasting,
- runs a frequent-itemset data-mining baseline,
- serves an interactive Streamlit dashboard to inspect graph slices and compare mining vs GNN outputs.

2) High-Level Data Flow
A) Input corpus
- cs_citation_network/papers.csv
- cs_citation_network/citations.csv

B) Topic extraction
- build_topics.py -> topics_out/topics.json, phrase_to_topic.csv, paper_to_topic.csv, paper_phrases.json

C) Hypergraph construction
- build_graph.py + topics_out + papers.csv -> hypergraph.pt, hypergraph_summary.txt, hypergraph.gexf

D) Modeling
- run.py trains THGNN residual model from hypergraph.pt and optionally papers.csv
- output model artifact: thgnn_residual_model.pt

E) Dashboard
- streamlit_app.py + frontend_services.py load outputs and render the interactive app

3) Root-Level Files
- build_topics.py
  Topic Builder v2. Extracts and normalizes phrases, scores phrase quality, builds co-occurrence graph,
  performs Louvain community detection + split/merge refinement, generates labels, exports topic artifacts.

- build_graph.py
  Converts topic outputs into a keyword-paper hypergraph for PyTorch Geometric.
  Writes tensors/metadata in hypergraph.pt and text/graph exports.

- run.py
  THGNN training/inference pipeline for topic residual prediction.
  Contains curve-family baselines (logistic/exp/power), temporal windowing, model train/eval logic.

- frontend_services.py
  Dashboard backend service layer: data loading, snapshot building, mining and GNN orchestration,
  and result dataclasses used by Streamlit.

- streamlit_app.py
  Main UI app. Renders graph and analytics panels, controls, forms, and Plotly/canvas visualization.

- hypergraph.pt
  Latest generated hypergraph tensor bundle.

- hypergraph_summary.txt
  Human-readable stats for hypergraph.pt (nodes, edges, incidences, features, topic labels).

- hypergraph.gexf
  Graph export for Gephi/graph tooling.

- thgnn_residual_model.pt
  Saved trained THGNN model checkpoint artifact.

- data_mining_problem_prediction.tex
  LaTeX document for the data-mining approach write-up.

- gnn_problem_prediction.tex
  LaTeX document for the GNN approach write-up.

- test.html
  Standalone HTML page likely used for visualization/testing experiments.

9) Typical Commands
- Rebuild topics:
  python build_topics.py --input cs_citation_network/papers.csv --out topics_out

- Rebuild hypergraph:
  python build_graph.py --papers_csv cs_citation_network/papers.csv --topics_dir topics_out --out .

- Run dashboard:
  streamlit run streamlit_app.py

- Run THGNN pipeline:
  python run.py

10) Notes
- The workflow is data-first: regenerate topics_out before hypergraph when topic logic changes.
- The dashboard consumes generated artifacts; stale files can cause mismatched visuals.
- LaTeX files provide narrative/report context but are not required for runtime execution.
